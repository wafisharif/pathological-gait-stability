Project Goal

Build a framework that uses publicly available pathological gait data to create population-specific locomotion controller variants and compare their stability within a shared simulation environment.

Current Pipeline

1. Identify public gait datasets
2. Extract population-specific gait characteristics
3. Modify a baseline walking controller
4. Create population-specific controller variants
5. Evaluate stability and robustness
6. Compare populations

Candidate Populations

- Healthy controls
- Parkinson's disease
- Stroke
- ALS
